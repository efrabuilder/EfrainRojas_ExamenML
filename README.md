# TicoShop · ¿Qué clientes van a dejar de comprar?

Examen de la Unidad 5 del curso Fundamentos de Ciencias de Datos. Análisis de 2 000 clientes de TicoShop para detectar el abandono a tiempo y decidir a quién contactar primero.

## Contenido
- `EfrainRojas_ExamenML.ipynb`: cuaderno con el código, los resultados y las respuestas.
- `EfrainRojas_ExamenML.pdf`: versión en PDF del cuaderno.
- `index.html`: versión web del informe.

## Qué incluye
1. Exploración: qué distingue a quienes dejaron de comprar.
2. Segmentación con K-Means (4 segmentos).
3. Cinco modelos de clasificación, evaluados contra una línea base.
4. Factores que suben o bajan el riesgo de irse.
5. Plan de acción para mercadeo, sin términos técnicos.

## Tecnologías
Python, pandas, scikit-learn, matplotlib, seaborn y Google Colab.
